# INVENTORY — the single tracker

This is THE tracker for this project: one table of every item ever asked for, merged from
eight sources (session rulings, seed/DECISIONS.{md,json}, seed/OBJECT{,-AMENDED}.md,
seed/GATES.md, registry/{PREREG.md,REGISTRY.jsonl}, the seed manifests, the commit log,
in-code markers and controls, the live deploy, and the open GitHub PRs). Duplicates across
sources are merged into one row carrying the strongest evidence and the weakest status.

**DONE means DONE.** A row is `DONE-wire-verified` only when the property was observed on the
served URL (or in a committed artifact produced against it) or a handed-over artifact exists.
`DONE-code-only` means the code and its control exist and the suite is green, and nothing more.
A green test suite does not declare anything usable.

**This file is regenerated, never edited by hand.** Editing a row instead of re-deriving it is
how a tracker becomes a second, softer record of the same facts.
