## PART I — THE OBJECT

### §10 — THE NULL SURFACE (normative, CLOSED)

**The interface is conversation. Nothing else is on it.** One box, the answer, and the raw LM
traffic. No mode selector, no persistence checkbox, no claim gesture, no accept, no reject.

**THE DERIVATION, UPDATED.** The two binary coordinates were correctly READ OFF the object —
objecthood and persistence are genuinely independent and genuinely binary, and the 2×2 that
followed was forced. The error was one level up: neither coordinate needed a SURFACE, because
both **collapse into the physics**.

- **OBJECTHOOD collapsed.** Every operator utterance is an authored record. It enters the tape
  directly — journaled, provenance-stamped, born aging, immediately energy-visible — so there
  is no selector, because there is no second kind of thing to select. There is no gate in
  front of speech.
- **PERSISTENCE collapsed.** Aging contracts what nothing confirms and **K is the only door to
  slow weight** — for the operator's words exactly as for the medium's. Conclusions earn
  promotion; thinking-out-loud decays. A retain checkbox pre-declared, before any measurement,
  an answer the physics already computes from measurement.

**AGREEMENT IS CONVERSATIONAL.** Agreeing means restating in your own words, which is your own
record. The walk then measures the `same_claim` between yours and the medium's, and if it holds
the apex machinery compresses them to one proposition. **There is no transfer act.** The
authorship-transfer path does not exist anywhere; OI-41's planted control remains as a
tombstone, so rebuilding the door is loud rather than quiet.

**FREQUENCY IS PROVENANCE, NOT COPIES.** An exact repeat resolves to the same address and
appends a new journal event. Paraphrases are new slots until the walk measures them the same
claim. Compute therefore scales with the DIVERSITY of propositions and measured arrows, never
with how often something is said.

**STRUCTURE IS UNTOUCHED BY CONVERSATION.** Talking can only add slots over charts that already
exist. The type system makes drift inexpressible; its controls stand.

**THE PRIOR DESIGN** — the 2×2, the assert/brainstorm selector, retain, the claim pullback and
the ACT speech-reader — is in `archive/design/2026-08-07-two-coordinate-surface.md` and
`archive/design/2026-08-07-mode-claim-posture-modules.md`, with its reasoning intact. It was
superseded, not refuted: the derivation was sound and the premise was wrong.

## PART II — THE CARRIER

### §6b — THE LM BOUNDARY, TYPED (normative)

The ports are three-layer typed interfaces. Every byte crossing the boundary belongs to
exactly one layer or is unconstitutional (B5).

**LAYER 1 — the mathematical object (derived):**
- `propose`: finite diagram D ⊂ carrier → partial set of triples in D×K×D (none is legal)
- `render`: (SettledState, Question_RAW) → image in the target chart satisfying the output
  grammar. **The question travels VERBATIM** (OI-19).

**LAYER 2 — our serialization** (each element derived or razor-controlled):
- **indices** — the medium may point, never name (resolve-or-void)
- **shuffle** — serialization adds zero information; order is a covert ranking channel
- **byte-exact ν** — judged text must hash to the address (gate 1)
- **legend entries** — symbol→meaning pairs for OUR notation ONLY
- **the task verb** — the MORPHISM SELECTOR, function application serialized. "Complete the
  diagram" selects `propose`; "answer the question from this state" selects `render`. Not
  style: the name of the arrow being requested.
- **output-syntax lines** — the CODOMAIN'S SYNTAX stated (`[n]` per sentence, `[∅]` for
  absence). The type annotation; **the checker is the typechecker.** Syntax yes, policy never.

**LAYER 3 — the peripheral's envelope (CONFESSED transport):** role-tagged messages, token
mechanics, decode temperature. Zero theoretical content. Constraints: enumerable,
byte-inspectable, injection-controlled.

**THE RAZOR** (standing control, sentence-level): every sentence in either channel is exactly
one of (a) a legend symbol→meaning, (b) the task verb, (c) codomain syntax — or it is state. A
sentence describing the MECHANISM, the EPISTEMICS, or a PREFERENCE is relocated editorial =
**RED**. The fixture checks sentence-type membership, not character count: 495 chars passes
today, and the razor keeps it passing when someone adds a helpful sentence in October.
