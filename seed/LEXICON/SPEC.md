# LEXICON SPEC — hub of faces, not hub of truth

Addendum to KICKOFF. Frozen under `SEED.lock`. Gates 1, 2 and 4 apply to everything here.

## 0. Topology — the hub invariant

One registry. Per-chart **faces**.

```
entry   = {entry_id, senses[]}
sense   = {english_face*, formal_faces[], type_sig, frames, source, source_beta, synonym_edges[]}
                  ^ mandatory
```

Two halves, both load-bearing, enforced separately:

**(a) English face is mandatory.** Every sense of every entry has one. An import arriving
without one — a bare Mathlib name — gets one generated by the R-map (`engine/rmap.py`) and
marked `warrant="rendered"`: regenerable, disposable, and counted as a quality metric by
null cell (vi). No entry may exist only in a formal chart. English-only entries are fine;
coverage asymmetry is expected and is not a defect.

**(b) Warrant never flows through the English face.** Authority lives on the spokes —
kernel names, typed signatures, test receipts — at their source beta. The English face
addresses and renders. It grounds nothing.

This is enforced by construction, not by convention. The F-visible projection of a sense is
`SenseCore`, and `SenseCore` **does not have an `english_face` field**. It carries
`english_slot` — the *hash*, which is the address — and never the string. `english_face`
and `gloss` live on `SenseDisplay`, which no F-constructing code path can reach.

| F-visible (`SenseCore`) | Display-only (`SenseDisplay`) |
|---|---|
| `english_slot` (hash, not string) | `english_face` (string) |
| `type_sig` | `gloss` |
| `frames` | `notes` |
| `formal_faces` (kernel names — authoritative) | |
| `synonym_edges` (as energies) | |
| cross-chart `bindings` | |

Null cell (viii) is a static AST check that no F-path module reads `.english_face`,
`.gloss`, or `.display`. Gate 2, made grep-able at the lexicon layer.

### On `source_beta`

The addendum calls a sense's source-authority weight `beta`. KICKOFF already uses `beta`
for the meter's inverse temperature (arms `{1x, 4x}`). They are unrelated quantities. This
codebase calls the lexicon one **`source_beta`** everywhere, so a log record carrying both
is unambiguous. Values live in `seed/CONSTANTS.json` under `lexicon.source_beta`.

## 1. Import order

Order matters: later imports must not shadow earlier ones. The importer runs them in this
sequence and refuses to run them in any other.

| # | Source | Pin | Contributes | Notes |
|---|---|---|---|---|
| 1 | Mathlib dump | commit hash | names + type signatures + docstrings + namespace-as-taxonomy | **Pre-bound** (formal face and gloss arrive together) — the highest-quality entries. Imported first so they own their addresses. |
| 2 | Convention table | file hash | pre-fibered sense-splits + declared bridges | Hand-seeded. Lands **before any corpus ingestion**. |
| 3 | nLab alias/redirect scrape | scrape date | synonym edges, aliases | Curated-tier `source_beta`. nLab glosses are perspectival: import **edges and aliases, not authority**. |
| 4 | Repo pre-minted files | D5 file hashes | domain senses | High warrant by authorship provenance. **Never merged** into imported general senses. |
| 5 | WordNet-grade general English | version | gap-fill only | **Last.** The collision policy is what stops general senses shadowing technical ones. |

## 2. Collision policy — never auto-merge

- **Same lemma across imports: never merge by string.** Senses are keyed by
  `(lemma, type_sig, source)`. "field" arrives at least three times — algebra,
  physics-adjacent general, WordNet — and all three live as senses.
- **Sense selection at ingestion is by typed context** (frame + slot neighbourhood). When
  the text does not decide it, the result is an honest fiber `{sense_a, sense_b, abstain}`.
  A coin flip here is a seed bug, so `select_sense` returns a fiber rather than picking.
- **Merging senses is plastic and mint-gated**, driven by co-settlement evidence later.
  Never at import time. `engine/lexicon.py:merge_senses` raises at v0 (mint is OFF).
- **When two imports disagree** — a Mathlib docstring against an nLab gloss for the same
  formal face — keep both glosses attached at their own `source_beta`. Disagreement between
  sources is data, not a dedup task.

## 3. Mechanics

- **Idempotence.** The importer re-run at the same pinned hashes produces a byte-identical
  registry. Any diff is a bug. Serialization is canonical JSON, sorted throughout.
- **Pins in `SEED.lock`** (`lexicon_pins`): Mathlib commit, nLab scrape date, WordNet
  version, convention-table hash, **importer script hash**. The last one means editing
  `adapters/lexicon_imports.py`, `engine/lexicon.py`, or `engine/rmap.py` moves the seed
  hash — which is correct, because those files decide addresses.
- **Every import batch is a logged seed event.** Post-lock additions are seed-morphisms
  under gate 4: logged, slot-mapped, cold-annealed.
- **No silent normalization of source data.** Mathlib names are not case-folded and
  namespace paths are not stripped — the namespace *is* taxonomy signal, and it is what the
  R-map disambiguates with. The Lean chart's `nu` already refuses to casefold; the importer
  additionally stores every formal-face surface verbatim.

## 4. Battery additions (null cells vi–ix, run at P1)

| Cell | Requirement | Failure means |
|---|---|---|
| vi. hub-coverage | every sense has an `english_face`; the count of `warrant="rendered"` faces is reported | a sense exists only in a formal chart — the hub invariant is broken |
| vii. shadow check | pre-registered technical terms resolve to technical senses in math-typed contexts and general senses in general contexts | general-English shadowing a technical sense ⇒ **seed rejected** |
| viii. no-clamp grep | static check: no gloss or `english_face` string is reachable from any F-constraint term | authority is flowing through the hub |
| ix. binding sanity | for 50 random Mathlib-derived senses, `english_face → nu → slot → binding` returns the originating formal face; **> 5% failures = importer bug** | the R-map or the binding index is not round-tripping |

## 5. Why this topology

English is the only chart with universal coverage: every technical object has an English
face, no formal chart can say everything, and humans read here. So the registry is a star
with English at the centre **for addressing and rendering**. But English is also the only
chart with no referee, so it must carry zero authority — warrant stays on the spokes
(kernel names, typed signatures, test receipts).

Hub of faces, not hub of truth. Both halves are load-bearing; both are enforced.
