### §10 — THE INTERACTION SURFACE (normative, CLOSED)

**The surface is not designed; it is READ OFF the object.** The operator's utterance is a
candidate object approaching the category. The type system exposes **exactly two independent
binary coordinates plus one constructible arrow**. Nothing else exists: every control
corresponds to an arrow in the diagram, or is absent because it must be.

**COORDINATE 1 — OBJECTHOOD (the warrant selector).** `AUTHORSHIP` or nothing. Below
`EXTRACTION` there is no tier because there is no claim. The utterance is either a CLAIM OF
THE OPERATOR'S — an object, carrying authorship warrant — or a PURE BOUNDARY CONDITION, an
external field term that is not an object at all. **Binary because objecthood is binary.**
UI name: **Assert / Brainstorm**.

**COORDINATE 2 — PERSISTENCE (the colimit selector).** Discard or keep. The input adjoins a
transient object to the diagram. Retain asks whether that extension is DISCARDED after
settling — a probe, the free object and its cone vanish — or KEPT, entering the tape born
aging. **Binary because a colimit is either taken or not.** UI name: **retain**.

**THE 2×2 IS FORCED AND COMPLETE** — the product of two two-element sets. No fifth state is
constructible.

| | retain = off | retain = on |
|---|---|---|
| **assert** | probe with authorship; nothing persists | the claim enters at AUTHORSHIP, born aging on the tape |
| **brainstorm** | open exploration; nothing persists | the medium's CITED proposals enter at EXTRACTION; **the prompt never enters** |

**THE ONE GESTURE — CLAIM (the authorship pullback).** A per-sentence affordance on anything
the medium said, in any mode, at any time. Firing it constructs a NEW object: same surface
text, operator authorship, entering through the normal inlet as an assertion. **Always
retains** — claiming-to-discard is incoherent. It is a **VERB, not a state**: an arrow the
operator fires, not a place the system sits. The medium's provenance is preserved
(`claimed_from: <record id>`) so the pullback is auditable.

**THE CLAIM GESTURE IS NOT A NEW WRITE-POINT.** It invokes the existing **perturb-retain**
write-point with authorship warrant and `claimed_from` provenance. The closed set
`{perturb.retain, walk.arrow, aging.decay, mz.promote}` is UNCHANGED (OI-33), and a claim
implemented as any other path must trip the existing write-point control.

**"ACCEPT" DOES NOT EXIST AND CANNOT BE ADDED.** It would be warrant increasing by approval
without authorship — a third arrow up the tier poset. The poset has exactly two lifts: **K
promotes by measurement; authorship enters by assertion.** An accept button is an arrow that
is not in the diagram, and its absence is constitutional (**OI-41**).

**THE THREE FATES** of anything on the tape, each an existing arrow and nothing new:

- **ignored** → the aging endomorphism (halving) contracts it toward zero
- **earning** → K's kernel measures its residual and reweights iff it qualifies
- **claimed** → the authorship pullback

### §10a — THE ACT IS READ, NOT PRE-SET (normative)

Same object, different presentation. The two coordinates and the one arrow are unchanged; what
changes is **where they are set from**. The attachment call emits an additional gated
coordinate — the READING of the utterance's act — and the toggles become **overrides**, with
read-from-speech the default.

- **Read like any proposal.** A declared token in a closed vocabulary (`ACT: explore
  keep-nothing`, `ACT: claim-of 7 keep`), EXTRACTION tier, through the one inlet,
  resolve-or-void. **Never inferred from prose:** a reading taken from the shape of a sentence
  would be a fluency judgement steering warrant.
- **THE CONSERVATIVE DIRECTION INVERTS.** Everywhere else an unknown mode defaults to ASSERT,
  because the risk is stripping warrant from something the operator meant to stand behind.
  When the machine is READING rather than being told, the risk reverses — a misread that
  invents a claim confers authorship nobody asserted. **When unsure whether you claimed,
  assume you didn't.** Ambiguity resolves to explore/keep-nothing.
- **Misreads are visible, never silent.** Every response opens with the reading; the next
  utterance corrects it, and a correction **re-stamps the prior record with an era trail** —
  the original reading is kept, not overwritten.
- **`claim-of [n]` resolves to the DISPLAYED BYTES or VOIDS.** Never paraphrased: a pullback
  onto a reconstruction would land on something the operator never read.
- **The locks are unchanged.** Authorship attaches only to operator words; the reading decides
  how an utterance is TREATED and confers nothing by itself.

**WHY THIS IS CLOSED.** Two binary indices plus one constructible arrow is the complete
free-parameter set the object exposes to the operator. Any future proposal to add a mode, a
strength slider, an accept control or a warrant knob **must first show which arrow of the
diagram it presents** — B5 applies.
